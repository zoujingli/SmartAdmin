# 接口字段索引

最后更新：2026-07-23

> 本页按当前源码抽取接口与字段合同，作为各接口参考页的字段级索引。路由来自 Controller 注解，写入字段来自 Service 校验，查询字段来自 Mapper 白名单，响应基础字段来自 Model；具体接口示例仍在各接口页维护。

## 抽取口径

| 来源 | 抽取内容 | 说明 |
|------|----------|------|
| Controller | `#[Controller]`、`#[GetMapping]`、`#[PostMapping]`、`#[PutMapping]`、`#[DeleteMapping]`、`#[Auth]`、`#[Logger]` | 确认方法、路径、认证、权限码和操作日志 |
| Service | `_vali()` 规则和内联校验字段 | 确认 body/form 写入字段、必填、类型、长度、枚举、默认值和业务错误提示 |
| Mapper | `_query()->like/equal/in/dateBetween` 与列表增强字段 | 确认 query 筛选白名单、日期范围字段和列表/详情派生字段 |
| Model | `$fillable`、`$hidden`、`$casts`、`$logRules` | 确认可写字段、隐藏字段、类型转换和审计中文字段 |

## 全局字段约定

| 字段 | 类型 | 适用范围 | 说明 |
|------|------|----------|------|
| `id` | integer | Model / path | 主键，详情、更新、状态、删除、恢复和彻底删除接口通常通过 path 传入 |
| `ids` | string | path | 批量 ID，逗号分隔，Controller 经 `idsOrFail()` / `deleteByIds()` 校验 |
| `tenant_id` | integer | Model | 租户字段；普通写接口由登录上下文确定，请求体不作为切换租户入口 |
| `status` | integer | Model / body / query | 通用启停状态，通常 `1` 启用、`0` 禁用 |
| `sort` | integer | Model / body | 排序字段，通常越大或越小的展示顺序由对应 Mapper 明确 |
| `created_by` / `updated_by` | integer | Model | 创建人与更新人，通常由框架或 Service 自动写入 |
| `created_at` / `updated_at` / `deleted_at` | datetime | Model | 创建、更新、软删除时间；`deleted_at` 通常隐藏或只在回收站出现 |
| `page` / `pageSize` | integer | query | 标准分页参数，列表接口默认走 `CoreMapper` 分页 |
| `task_linkable` | boolean | Project/System 需求列表及详情 query | 仅值 `1/true` 生效；只要求 `project.requirement.generate-task`，不额外要求 `project.requirement.index`；固定筛选当前租户、生成责任/数据范围内的 `approved` 需求，并允许仅关联可复用软删除纯净草稿的需求；列表保持数据库分页，详情复用相同门禁 |
| `start_date` / `after_date` | date/datetime | query | 新增跨字段范围统一边界；存量字段级范围可继续使用具体业务字段名 |

## 维护要求

- 新增 Controller 路由后，先更新具体接口页和完整接口清单，再同步本字段索引。
- 新增 Service `_vali()` 字段、Mapper 查询白名单或 Model `$fillable` 时，必须检查接口请求字段、响应字段和前端表单是否同步。
- 敏感字段需要同时检查 `#[Logger(excludeFields)]`、Model `$hidden`、全局脱敏规则和示例占位符。
- `composer docs:check` 负责路由覆盖和案例结构；字段语义仍需按本页列出的源码来源人工复核。

### 上传通道配置

`upload-config` 用于读取和保存服务端上传配置。保存配置时敏感字段会按点路径脱敏，例如 `drivers.oss.access_secret`、`drivers.cos.secret_key`。

| 配置块 | 说明 |
|--------|------|
| `active_mode` | 当前启用上传驱动 |
| `common.max_size_mb` | 单文件大小限制 |
| `common.chunk_threshold_mb` | 中转分块阈值，最终还会受服务端请求体上限约束 |
| `common.multipart_threshold_mb` | 对象存储分片直传阈值 |
| `common.part_size_mb` | 分片大小 |
| `common.allow_exts` | 允许后缀 |
| `drivers.local` | 本地存储配置 |
| `drivers.alist` | Alist 网关配置 |
| `drivers.qiniu` | 七牛云配置 |
| `drivers.oss` | 阿里云 OSS 配置 |
| `drivers.cos` | 腾讯云 COS 配置 |

### 标准上传流程

所有上传入口统一先调用 `POST /system/file/upload/prepare`。`prepare` 请求必须包含 `name`、`size`、`mime_type`、`hash` 和 `mode/scene`，服务端先校验权限、场景、后缀、MIME、大小和 hash，再执行秒传检查。秒传命中直接返回 `completed=true`、`transport=instant` 和 `asset`；未命中时创建上传会话并返回前端需要执行的上传指令。`upload_type` 仅允许空值、`direct`、`relay`：空值和 `direct` 都表示允许后端按当前通道能力调度直传或中转，`relay` 表示请求后端中转 fallback。

`transport` 取值：

| transport | 说明 |
|-----------|------|
| `instant` | hash 秒传命中，无需上传二进制 |
| `direct-single` | 后端签名单文件直传，前端直传成功后调用 `complete` |
| `direct-multipart` | OSS 大文件分片直传，前端逐片 `part-sign` 后调用 `complete` |
| `relay-single` | 服务端单文件中转 |
| `relay-chunk` | 服务端分块中转，避免大文件超过单次请求体上限 |

### 中转上传

小文件或需要服务端统一校验的文件可使用中转上传：

```http
POST /system/file/upload/relay
Content-Type: multipart/form-data
Authorization: Bearer <token>
```

常见表单字段：

| 字段 | 说明 |
|------|------|
| `file` | 上传文件 |
| `upload_session_id` | `prepare` 返回的中转上传会话 ID |

### 分片上传

大文件建议使用分片流程：

1. `prepare` 先秒传检查，未命中才创建上传会话，返回上传会话 ID、分片大小、分片数量和上传策略。
2. `relay-chunk` 上传服务端中转分块，最后一块由服务端合并、校验并写入文件记录。
3. OSS 直传分片场景通过 `part-sign` 获取单片签名，由前端上传到对象存储。
4. `complete` 只用于 `direct-single` 和 `direct-multipart` 直传会话，服务端确认远端文件并写入文件记录。
5. 上传失败或用户取消时调用 `abort` 清理会话。

常见分片字段：

| 字段 | 说明 |
|------|------|
| `upload_session_id` | 上传会话 ID |
| `chunk_index` | 分块序号，从 1 开始，不能超过 `total_chunks` 或 `prepare.part_count` |
| `total_chunks` | 总分块数，必须等于 `prepare.part_count` |
| `file` | 当前分块二进制，非最后一块不能超过 `prepare.part_size` |

### 权限与安全

- 文件管理接口需要菜单权限；上传流程只要求登录，但仍必须校验场景、大小、后缀、MIME 和驱动配置。
- 下载接口需要 `system.file.index` 权限，避免通过文件 ID 绕过管理权限。
- 签名下载接口不要求登录，访问权限由 `expires`、`attname`、`signature` 短期签名参数控制。
- 对象存储密钥只能保存在服务端配置中，前端只能拿到临时签名或必要的公开访问地址。
- 文件 URL 进入业务表后，删除文件记录前必须确认业务引用关系。

# 系统基础应用

系统基础应用上下文是通用后台控制面，负责身份、组织权限、租户、文件、审计、通知、调度和平台参数，不承载具体业务域。

## 身份与组织

**平台超级管理员**:
可维护跨租户平台能力和平台保留权限的管理主体。
_Avoid_: 超管、租户子超管

**租户子超管**:
在所属租户内自动拥有非平台保留权限的最高管理主体。
_Avoid_: 平台管理员、超级管理员

**租户**:
数据、身份和运行配置相互隔离的业务空间。
_Avoid_: 部门、默认租户

**部门**:
用于表达组织层级和部门数据范围的组织单元。
_Avoid_: 租户、岗位

**岗位**:
描述用户组织身份或职责的标签，不直接决定接口权限。
_Avoid_: 角色、部门

**角色**:
权限节点和数据范围的可分配集合。
_Avoid_: 岗位、用户组

## 权限与范围

**权限节点**:
可授予角色、并由接口最终校验的操作能力标识。
_Avoid_: 菜单、按钮

**菜单**:
声明目录、页面或按钮的前端入口及路由元数据。
_Avoid_: 权限节点、路由权限

**数据范围**:
主体已具备接口权限后，可读取或操作的数据集合。
_Avoid_: 租户范围、菜单权限

## 文件、审计与通知

**文件记录**:
平台管理的文件元数据、归属和业务引用入口。
_Avoid_: 物理对象、业务附件

**上传通道**:
文件写入所使用的存储驱动和运行规则。
_Avoid_: 上传会话、文件记录

**上传会话**:
从准备到完成或终止的一次文件传输过程。
_Avoid_: 上传通道、文件记录

**操作日志**:
一次登录、请求或管理动作的审计主体。
_Avoid_: 请求日志、变更日志

**变更日志**:
一次操作中某个业务对象字段变化的审计明细。
_Avoid_: 操作日志、请求日志

**公告**:
管理员维护、可向指定用户投放的通知主记录。
_Avoid_: 收件记录、外部消息

**收件记录**:
公告与单个用户之间的未读、已读和归档事实。
_Avoid_: 公告状态

## 调度

**定时任务定义**:
由代码注册、允许调度执行的白名单能力。
_Avoid_: 任务计划、任意命令

**任务计划**:
把任务定义绑定到租户、业务归属和运行周期的安排。
_Avoid_: 定时任务定义、业务任务

**任务归属**:
任务计划所服务的插件业务资源。
_Avoid_: 租户、执行人

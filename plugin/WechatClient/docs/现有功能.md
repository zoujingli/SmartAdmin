# 微信公众号平台现有功能

本文梳理 Apache-2.0 开源 `WechatClient` 插件。它使用 System 后台身份和权限管理租户侧公众号、小程序、内容资源与微信支付，不提供独立业务登录入口。

## 模块边界

- 管理租户自己的公众号、小程序、粉丝、菜单、回复、素材和文章。
- 管理微信支付 APIv3 商户、支付流水和退款流水。
- 可直连微信或通过开放平台网关调用，但不拥有第三方平台授权流程。

## 已落地能力

| 功能域 | 当前能力 |
| --- | --- |
| 接口账号 | 绑定公众号/小程序、维护安全配置、回调入口和 SDK 调用方式 |
| 粉丝管理 | 粉丝列表、本地标签、官方同步和同步记录 |
| 菜单发布 | 维护菜单树、关联内容资源、预览并发布微信自定义菜单 |
| 自动回复 | 关注、默认、关键词、菜单点击和关注后延时多回复 |
| 素材管理 | 永久素材、本地文件关联、官方同步和上传 |
| 文章管理 | 本地图文草稿、上传微信草稿和图文发布状态 |
| 支付商户 | APIv3 商户号、证书、密钥、回调地址和安全脱敏 |
| 支付订单 | 支付流水、状态查询、主动查单和退款入口 |
| 退款记录 | 退款流水、状态同步、主动查退和异常排查 |

## 关键流程

- 接口账号建立后，粉丝、菜单、回复、素材和文章都以该账号作为微信资源边界。
- 菜单和文章先在本地维护，再显式调用微信接口上传或发布；本地保存不等于微信侧已经生效。
- 支付与退款先记录本地流水，回调或主动查询用于同步官方状态；查询动作不应伪造交易结果。

## 权限与安全边界

- 管理页面复用 System 登录态，并由 `wechat.client.*` 权限节点控制。
- AppSecret、Token、EncodingAESKey、APIv3 Key、私钥和证书等秘密字段脱敏保存和展示。
- 粉丝、素材、文章、菜单和支付记录都受租户及接口账号归属限制。
- 微信开放平台第三方授权、Ticket 和网关凭据由另一个插件负责，本插件只消费授权后的调用能力。

## 合理推测

- 当前账号抽象可以继续承载更多公众号和小程序接口，但不能据此宣称已覆盖微信全部能力。
- 支付流水和主动查询可以支持业务订单对账，但业务订单本身应由消费插件拥有。

## 当前不应宣传为已实现

- 企业微信、视频号、微信广告或完整小程序业务后台。
- 本地保存菜单、文章后自动绕过人工动作发布到微信。
- 以支付订单替代具体业务插件的订单和交付状态。

## 主要证据

- `plugin.json`：9 个页面、开源分发和权限清单。
- `src/Controller`、`src/Service`：账号、粉丝、菜单、回复、素材、文章和支付接口。
- `stc/view`：对应管理页面。
- `tests/Unit/WechatClient`：菜单、消息、支付和插件合同测试。

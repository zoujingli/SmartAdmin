# 微信公众号平台

微信公众号平台上下文负责租户侧公众号、小程序及微信支付资源的日常运营，既可直连微信，也可借助已授权的开放平台账号。

## 账号与内容

**接口账号**:
租户绑定的公众号或小程序身份及其接口、回调和安全配置。
_Avoid_: 授权账号、支付商户

**粉丝**:
关注公众号并以 OpenID 标识、可同步资料和本地标签的微信用户。
_Avoid_: System 用户、会员

**自定义菜单**:
在公众号会话界面展示、可关联点击动作和内容资源的菜单树。
_Avoid_: System 菜单、导航

**回复规则**:
针对关注、默认消息、关键词或菜单点击事件生成回复的匹配约定。
_Avoid_: 客服消息、文章

**永久素材**:
同步或上传到微信、可被菜单和图文内容引用的图片、音频、视频等资源。
_Avoid_: 本地文件、文章

**图文文章**:
在本地维护并可上传为微信草稿、进一步发布的图文内容。
_Avoid_: 永久素材、官网内容

## 支付

**支付商户**:
持有微信支付 APIv3 商户号、证书、密钥和回调配置的收款身份。
_Avoid_: 接口账号、接口应用

**支付订单**:
记录一次微信支付交易及其本地与官方状态的流水。
_Avoid_: 退款记录、业务订单

**退款记录**:
针对支付订单发起并同步微信退款状态的独立流水。
_Avoid_: 支付订单、撤销支付
